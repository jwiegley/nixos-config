** Close Reason

Implemented as a default-deny guard chain (John's choice). nixos-fw-ifguard is inserted at nixos-fw position 3 — after NixOS's invariant lo and ESTABLISHED,RELATED accepts, before every port accept — with a RETURN per legitimately-served interface (end0, wlp1s0f0, podman0, hermes-br0, ve+, vm+) and nixos-fw-refuse at the end. Any FUTURE interface therefore inherits nothing.

Implementation note: the obvious form 'iptables ! -i a ! -i b ...' is IMPOSSIBLE — iptables 1.8.11 rejects it with 'multiple --in-interface options not allowed'. Caught by validating the syntax in a throwaway chain before switching; it would otherwise have broken the firewall start script.
